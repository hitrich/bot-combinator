# BDEX readiness

Status: preview guidance

Use authoritative BDEX documentation when it becomes available. This preview only defines the evidence Klineo expects.

## Identity and interface

- Verified venue/environment.
- Verified assets, decimals, contract addresses, pool identifiers, and fee parameters.
- Versioned interface/API/ABI source.
- Explicit handling for unsupported assets, pools, and environments.

## User flow

- Discovery and pool/market selection.
- Quote source, timestamp, expiry/freshness, amount units, and price-impact display.
- Wallet/account/network validation before a transaction request.
- User review, rejection, pending, confirmed, failed, replaced, and dropped states.

## Market and launch evidence

- Pair and liquidity plan.
- Data source and monitoring owner.
- Depth/price-impact methodology.
- Pause/escalation conditions.
- Launch and post-launch reconciliation evidence.

No BDEX compatibility claim is complete without current source, environment, identity, flow, and verification evidence.
