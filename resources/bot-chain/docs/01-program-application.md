# Program application evidence

Status: preview guidance

Applicant teams retain their private local CRM. Klineo receives only a deliberate, reviewable submission.

## Project identity

- Canonical project and legal/entity name where applicable.
- Website, public product links, and primary operating contact.
- Team roles and the person authorized to make program decisions.
- Conflicts or identity ambiguities requiring review.

## Product and market

- User problem and product summary.
- Current build/demo status.
- Target users and evidence of demand/adoption.
- Roadmap through the proposed cohort and launch window.

## Technical and security

- Architecture and supported platforms.
- Repository/build/test state the team is willing to disclose.
- Contract review/audit status and unresolved findings.
- Key-management, incident, and escalation owners.

## BOT Chain program request

- Requested BOT Chain, BDEX, BO Wallet, liquidity, launch, and public-program support.
- Proposed milestones and responsible owners.
- Known blockers and missing authoritative documentation.
- Visibility approval for each submitted document or field.

The submission is versioned and immutable. A later update creates a new submission rather than rewriting the record Klineo reviewed.
