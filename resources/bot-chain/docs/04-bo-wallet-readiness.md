# BO Wallet readiness

Status: preview guidance

Use authoritative BO Wallet documentation when it becomes available. This preview defines expected integration evidence.

## Connection states

- Wallet unavailable or unsupported.
- Disconnected, connecting, connected, locked, and expired session.
- Correct/wrong/unknown network.
- Account changed or disconnected.

## Signing path

- Exact user action that initiates a signature or transaction request.
- Human-readable review details before the wallet prompt.
- User rejection and safe recovery.
- Pending, confirmed, failed, replaced, and dropped outcomes where applicable.
- No private key/seed material crossing the application boundary.

## Discovery and support

- BOT Chain environment configuration source.
- Asset/network discovery evidence.
- Supported platforms and tested wallet versions.
- Troubleshooting and escalation owner.

Do not state BO Wallet integration is verified until a designated project reviewer records evidence for the target environment.
