# Start here

Status: preview guidance

This pack helps an applicant team prepare, implement, and evidence BOT Chain integration while continuing to use the complete Bot Combinator fundraising workspace.

## What this preview establishes

- A repeatable application and readiness workflow.
- Clear evidence expectations for BOT Chain, BDEX, BO Wallet, liquidity, security, and launch work.
- Safe handoff instructions for Codex or Claude.
- A rule that missing technical values remain unknown rather than being guessed.

## What is not yet in this preview

Authoritative BOT Chain network identifiers, RPC/explorer URLs, contract addresses, ABIs, BDEX interfaces, and BO Wallet integration behavior have not been supplied. Do not use this pack as the technical source for those values.

## Recommended path

1. Complete the program application evidence in `01-program-application.md`.
2. Assess the integration plan with `02-bot-chain-integration-readiness.md`.
3. Use the BDEX and BO Wallet readiness documents for the selected scope.
4. Complete liquidity/launch and security/testing evidence.
5. Submit only the records and documents the project approves for Klineo review.

Every submission should identify its bundle version, document versions, environment, evidence owner, and UTC verification time.
