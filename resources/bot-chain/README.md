# BOT Chain integration pack

This versioned pack is distributed through the Bot Combinator BOT Chain Docs workspace.

The current `0.1.0-preview` bundle contains Klineo-authored workflow, readiness, safety, and application guidance. It deliberately does not contain production chain IDs, RPC URLs, contract addresses, ABIs, BDEX endpoints, or BO Wallet implementation claims. Those values remain unknown until authoritative BOT Chain-owned documentation is supplied and approved.

Start with `BotAgents.md` when using a repository-capable coding agent. Human readers should begin with `docs/00-start-here.md`.
